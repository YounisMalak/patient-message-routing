סווג הודעות מטופלים לקטגוריה אחת מתוך שש קטגוריות.

## קטגוריות:

### RX (renewal) - חידוש מרשם
בקשות לחידוש מרשמים לתרופות קיימות.
**מילות מפתח:** חידוש מרשמים, tab, cap, box, 5mg, 30mg, 25mg, 20mg, 10mg, 100mg

### ILL (sicknote) - אישור מחלה
בקשות לאישורי מחלה לעבודה או ללימודים.
**מילות מפתח:** אישור מחלה, חופשת מחלה, מחלה חופש, אישור מחלה, מחלה אישור, ימי מחלה, מכתב מחלה לעבודה, מכתב מחלה, אישור מחלה לעבודה

### ADMIN (office) - משרדי
בקשות אדמיניסטרטיביות: תורים, טפסים, תוצאות בדיקות, מסמכים.
**מילות מפתח:** החזר, עבור החזר, התחייבות תרופות, התחייבות כספית, טופס 17, חשבונית, טופס, טלפון, לחו"ל, מספר חשבון

### RN (nurse) - אחות
בקשות לשירותי אחות: זריקות, חיסונים, מדידות, החלפת תחבושות.
**מילות מפתח:** להתחסן, בדיקת לחץ דם, דיפטיריה, השלמת חיסון, טטנוס, טיפול פצע, מרשם לחבישה, מרשם לקטר, HPV, DPT

### NORMAL (doctor-not-urgent) - רופא לא דחוף
ייעוץ רפואי לא דחוף, הפניות, התייעצות על תסמינים לא חריפים.
**מילות מפתח:** גסטרו ילדים, הפניה, הפניה MRI, הפניה א.ק.ג, הפניה לאולטרסאונד, הפניה לאולטרסאונד שד, הפניה בדיקות דם, הפניה ממוגרפיה, חיסון prevnar, חיסון דלקת ריאות

### STAT (doctor-urgent) - רופא דחוף
מצבים הדורשים טיפול מיידי: כאב חזה, קוצר נשימה, חום גבוה מאוד, דימום חמור.
**מילות מפתח:** פציעות ראש, שיתוק, קוצר נשימה, כאב חזה, חבלה בראש, נשיכה, נפיחות בפנים, גרד בעין, דחוף, דימום חזק

## כללי עדיפות:
1. בקשה לחידוש מרשם (גם עם תסמינים) -> RX
2. בקשה לאישור מחלה (גם עם תסמינים) -> ILL
3. בקשה למרשם חדש עם תסמינים -> NORMAL
4. תסמינים דחופים בלבד (ללא בקשה אחרת) -> STAT
5. שירותי אחות (זריקות, מדידות) -> RN

## דוגמאות:
הודעה: "דם לחץ לכדור מרשם לחדש" -> תשובה: RX
הודעה: "מחלה אישור צריכה חום לי יש" -> תשובה: ILL
הודעה: "פנוי תור יש מתי" -> תשובה: ADMIN
הודעה: "B12 זריקת צריך" -> תשובה: RN
הודעה: "לסירופ מרשם צריך שיעול לי יש" -> תשובה: NORMAL
הודעה: "נשימה וקוצר בחזה חזקים כאבים" -> תשובה: STAT
הודעה: "והקיא הראש על נפל הילד" -> תשובה: STAT

ענה במילה אחת בלבד: RX / ILL / ADMIN / RN / NORMAL / STAT
